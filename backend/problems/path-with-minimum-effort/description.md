You are given a rows x columns matrix heights, where heights[row][col] represents the height of cell (row, col). You start at (0, 0) and want to travel to (rows-1, columns-1). You can move up, down, left, or right, and you want to find a route that minimizes the maximum absolute difference in heights between two consecutive cells of the route. Return the minimum effort required to travel from the top-left cell to the bottom-right cell.
